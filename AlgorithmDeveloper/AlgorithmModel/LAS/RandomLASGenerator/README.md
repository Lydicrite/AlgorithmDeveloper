# RandomLASGenerator

Модуль для генерации случайных корректных ЛСА (Логических Схем Алгоритмов) с использованием конечного автомата и вероятностных переходов.

## Описание

RandomLASGenerator создает случайные, но корректные ЛСА строки, которые соответствуют правилам парсера `LASParser` и спецификации из `ЛСА.md`. Генератор использует конечный автомат с вероятностными переходами между состояниями для создания разнообразных и валидных алгоритмических схем.

## Основные компоненты

### 1. IRandomLASGenerator
Интерфейс, определяющий методы генерации:
- `GenerateByMinTokenCount(int minTokenCount, int? seed = null)` - генерация с минимальным количеством токенов
- `GenerateByOperatorVertexCount(int operatorVertexCount, int? seed = null)` - генерация с указанным количеством операторных вершин
- `GenerateByConditionalVertexCount(int conditionalVertexCount, int? seed = null)` - генерация с указанным количеством условных вершин
- `Generate(LASGenerationOptions options)` - генерация с настраиваемыми параметрами

### 2. RandomLASGenerator
Основной класс генератора, реализующий интерфейс `IRandomLASGenerator`. Использует конечный автомат для пошаговой генерации токенов ЛСА.

### 3. LASGenerationOptions
Класс настроек генерации, включающий:
- Минимальное количество токенов
- Минимальное количество операторных и условных вершин
- Вероятности переходов между состояниями
- Максимальное количество попыток генерации
- Seed для детерминированной генерации

### 4. LASGenerationState
Перечисление состояний конечного автомата:
- `Start` - начальное состояние
- `AfterStart` - после стартовой вершины
- `AfterOperator` - после операторной вершины
- `AfterConditional` - после условной вершины
- `InLeftBranch` - в левой ветви условной вершины
- `InRightBranch` - в правой ветви условной вершины
- `AfterJumpPoint` - после точки перехода
- `CanFinish` - возможность завершения
- `Finished` - завершенное состояние

### 5. LASGenerationContext
Контекст генерации, отслеживающий:
- Текущее состояние автомата
- Сгенерированные токены
- Счетчики различных типов вершин
- Стеки открытых переходов и состояний
- Ограничения генерации

### 6. LASValidator
Валидатор для проверки корректности сгенерированных ЛСА с использованием существующего парсера.

## Принцип работы

Генератор работает как конечный автомат с вероятностными переходами:

1. **Инициализация**: Начинается с состояния `Start` и добавления стартовой вершины `Yн`
2. **Пошаговая генерация**: На каждом шаге выбирается следующее действие на основе:
   - Текущего состояния
   - Вероятностей переходов
   - Ограничений (минимальное количество токенов/вершин)
3. **Управление ветвлением**: Отслеживает открытые условные переходы и обеспечивает их корректное закрытие
4. **Валидация**: Проверяет корректность сгенерированной ЛСА с помощью существующего парсера
5. **Повторные попытки**: При неудачной генерации делает новые попытки до достижения лимита

## Примеры использования

### Базовая генерация
```csharp
var generator = new RandomLASGenerator();
var las = generator.Generate(LASGenerationOptions.Default);
Console.WriteLine(las); // Например: "Yн Y1 Yк"
```

### Генерация с минимальным количеством токенов
```csharp
var las = generator.GenerateByMinTokenCount(10);
Console.WriteLine(las); // ЛСА с минимум 10 токенами
```

### Генерация с указанным количеством вершин
```csharp
var las = generator.GenerateByOperatorVertexCount(3); // 3 операторные вершины
var las2 = generator.GenerateByConditionalVertexCount(2); // 2 условные вершины
```

### Детерминированная генерация
```csharp
var las1 = generator.GenerateByMinTokenCount(5, seed: 42);
var las2 = generator.GenerateByMinTokenCount(5, seed: 42);
// las1 == las2 (одинаковые результаты)
```

### Настраиваемая генерация
```csharp
var options = new LASGenerationOptions
{
    MinTokenCount = 15,
    MinOperatorVertexCount = 3,
    MinConditionalVertexCount = 2,
    OperatorVertexProbability = 0.4,
    ConditionalVertexProbability = 0.3,
    JumpProbability = 0.2,
    MaxAttempts = 1000
};

var las = generator.Generate(options);
```

## Тестирование

Модуль включает комплексный набор тестов в классе `RandomLASGeneratorTests`:

- **Базовая генерация**: Проверка корректности основной функциональности
- **Ограничения по токенам**: Проверка соблюдения минимального количества токенов
- **Ограничения по вершинам**: Проверка генерации указанного количества операторных/условных вершин
- **Детерминированность**: Проверка воспроизводимости результатов с одинаковым seed
- **Валидация**: Проверка корректности всех сгенерированных ЛСА
- **Производительность**: Измерение скорости генерации

### Запуск тестов
```csharp
var tests = new RandomLASGeneratorTests();
var results = tests.RunAllTests();
Console.WriteLine($"Пройдено: {results.PassedCount}/{results.TotalCount}");
```

## Архитектурные особенности

### Конечный автомат
Генератор реализован как конечный автомат, где каждое состояние соответствует определенному этапу формирования ЛСА. Переходы между состояниями происходят с заданными вероятностями, что обеспечивает разнообразие генерируемых схем.

### Управление ограничениями
Система ограничений позволяет:
- Задавать минимальное количество токенов
- Контролировать количество различных типов вершин
- Обеспечивать корректное завершение всех открытых переходов

### Валидация
Интеграция с существующим парсером `LASParser` гарантирует, что все сгенерированные ЛСА являются корректными и могут быть успешно разобраны.

### Производительность
Генератор оптимизирован для быстрой работы:
- Эффективное управление состоянием
- Ограничение количества попыток генерации
- Минимальное количество валидационных проверок

## Расширяемость

Модуль спроектирован с учетом возможности расширения:
- Легко добавлять новые состояния автомата
- Настраиваемые вероятности переходов
- Возможность добавления новых типов ограничений
- Модульная архитектура для интеграции с другими компонентами
